    Simulator

    Interactive simulator.

    Missing qubits are automatically appended in the all-zero state before a mutating operation.

    measure_observable 

    measure_observable(observable: str, *, flip_probability: float = 0.0) -> bool

    Measure a signed Hermitian Pauli product.

    The compact observable syntax has an optional leading sign followed by positional X, Y, Z, I, or _ factors, for example -X_YZ. Readout flipping occurs after a successful physical projection.

    Parameters:

    Name Type Description Default
    observable str

    Compact positional Pauli string.

    		 required
    flip_probability float

    Probability of flipping the reported bit.

    		 0.0

    Raises:

    Type Description
    ValueError

    If the observable or probability is invalid.
    MeasurementError

    If the projection is incompatible. Failure does not mutate state or RNG.

    Examples:

    from merlin import Simulator

sim = Simulator(seed=1234)
sim.reset_x(0, 1)
bit = sim.measure_observable("-XX", flip_probability=0.01)

    peek_observable_expectation(observable: str) -> float

    copy 

    copy(*, copy_rng: bool = False, seed: int | None = None) -> Self

    Copy the quantum state with configurable RNG behavior.

    By default the copy receives a fresh entropy-seeded RNG. Set copy_rng=True to reproduce the exact RNG state, or pass seed to use a chosen new stream.

    Raises:

    Type Description

    Examples:

    CircuitSampler

    Parse-once sampler backed by Simulator.

    A private noiseless replay is performed during construction to define the detector and observable reference parities. Every attempted shot otherwise starts from a fresh all-zero state and executes the circuit in source order.

    __init__ 

    __init__(circuit: str, *, seed: int | None = None, postselect: Sequence[int] | None = None) -> None

    Create a sampler and eagerly compute its noiseless reference.

    The circuit is parsed once. Each attempted shot then starts from a fresh all-zero Simulator and executes the circuit in source order.

    Parameters:

    Name Type Description Default
    circuit str

    Circuit source in the supported extended Stim format.

    		 required
    seed int | None

    Optional unsigned 64-bit seed for reproducible sampling.

    		 None
    postselect Sequence[int] | None

    Detector indices whose normalized True value rejects a shot. Indices must be unique and in range.

    		 None

    Raises:

    Type Description
    ValueError

    If the circuit or postselection mask is invalid.
    MeasurementError

    If noiseless reference generation encounters an incompatible measurement.

    num_qubits property 

    num_qubits: int

    Number of logical qubits referenced by the circuit.

    num_measurements property 

    num_measurements: int

    Number of measurement-record columns in a complete shot.

    num_detectors property 

    num_detectors: int

    Number of detector columns.

    num_observables property 

    num_observables: int

    Number of logical-observable columns.

    num_exp_vals property 

    num_exp_vals: int

    Number of expectation-value columns produced by EXP_VAL.

    num_fault_sites property 

    num_fault_sites: int

    Number of explicit noise and readout-fault sites.

    Batched single-qubit noise targets count separately, while two- and three-qubit noise groups count once. A measurement target is counted only when its readout probability was written explicitly, including an explicit probability of zero.

    sample 

    sample(shots: int, *, bit_packed: bool = False, num_faults: int | None = None) -> SampleResult

    Sample the circuit.

    Parameters:

    Name Type Description Default
    shots int

    Number of shots to attempt. Rejected postselected attempts are not replaced.

    		 required
    bit_packed bool

    Pack each boolean output family independently into little-endian uint8 rows. exp_vals remains float64.

    		 False
    num_faults int | None

    Sample uniformly from executions where exactly num_faults happen. Assumes that all fault sites have uniform proability and does not support PAULI_CHANNEL_1 or PAULI_CHANNEL_2 instructions.

    		 None

    Returns:

    Type Description
    SampleResult

    Measurement records, detector flips, observable flips, expectation
    SampleResult

    values, and attempted/accepted shot counts. Postselected attempts
    SampleResult

    are stopped at the rejecting detector and omitted from all arrays.
    SampleResult

    Successive calls continue the sampler's RNG stream.

    Raises:

    Type Description
    ValueError

    If shots or num_faults is negative.
    MeasurementError

    If a shot encounters an incompatible measurement. Randomness consumed before the failure remains consumed.

    Examples:

    from merlin import CircuitSampler

sampler = CircuitSampler(
    '''
    RX 0
    T 0
    EXP_VAL X0 Z0
    MX 0
    DETECTOR rec[-1]
    OBSERVABLE_INCLUDE(0) rec[-1]
    ''',
    seed=1234,
    postselect=[0],
)

assert sampler.num_qubits == 1
assert sampler.num_measurements == 1
assert sampler.num_detectors == 1
assert sampler.num_observables == 1
assert sampler.num_exp_vals == 2

result = sampler.sample(100)
assert result.total_shots == 100
assert result.discards == result.total_shots - result.accepted_shots
assert result.measurements.shape == (result.accepted_shots, 1)
assert result.detectors.shape == (result.accepted_shots, 1)
assert result.observables.shape == (result.accepted_shots, 1)
assert result.exp_vals.shape == (result.accepted_shots, 2)

packed = sampler.sample(100, bit_packed=True)
assert packed.measurements.dtype.name == "uint8"

    See Circuit instructions for the complete accepted circuit language.

    SampleResult

    Results returned by CircuitSampler.sample.

    Each array has one row per accepted shot. With unpacked sampling the three bit arrays have shape (accepted_shots, count) and NumPy bool dtype. With bit-packed sampling they have shape (accepted_shots, ceil(count / 8)), uint8 dtype, and independently padded little-endian rows. Expectation values are never packed and have shape (accepted_shots, num_exp_vals).

    measurements property 

    measurements: NDArray[bool_] | NDArray[uint8]

    Raw measurement records in circuit order.

    detectors property 

    detectors: NDArray[bool_] | NDArray[uint8]

    Detector flips relative to the noiseless reference sample.

    observables property 

    observables: NDArray[bool_] | NDArray[uint8]

    Logical-observable flips relative to the noiseless reference.

    exp_vals property 

    exp_vals: NDArray[float64]

    Expectation values from EXP_VAL, with NumPy float64 dtype.

    total_shots property 

    total_shots: int

    Number of attempted shots requested from the sampler.

    accepted_shots property 

    accepted_shots: int

    Number of rows that survived detector postselection.

    discards property 

    discards: int

    Number of attempted shots rejected by postselection.
